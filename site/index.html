Locate a PR

Paste a PR URL from a tracked repo. Your browser asks the GitHub API for that PR's reviews and comments (unauthenticated, 60 requests per hour), applies the same first-response rule as the pipeline, and places it in the repo's distribution. Nothing is sent anywhere else.

Governance

GitHub logins are replaced by salted SHA-256 keys before any data is written, so the public data branch and this page carry no usernames, and keys cannot be reversed by hashing a list of known logins without the secret salt. This page shows aggregates only. Pseudonymised data is still personal data under GDPR and Vietnam's personal data protection rules; see docs/governance.md.
